## Prerequisites

- **Node.js:** **v20.19.0+** or **v22.12.0+** (Angular 21 does **not** support Node 22.0–22.11.x; `ng serve` will exit with an engine error). Install from [nodejs.org](https://nodejs.org/).
- **npm:** this repo pins **`npm@11.8.0`** (`packageManager` in `package.json`). With Node 20.19+, you can run `corepack enable` then `corepack prepare npm@11.8.0 --activate` to match.
