  1. What this page is for

    The Assign Vendor page is the admin command center for a single service job. An account manager or dispatcher uses it to:

    Review job, customer, and location context before dispatching work

    Find and compare vendors (internal RFI vendors and AI-sourced external prospects)

    Assign one or more vendors to the job and send work orders

    Manage each assigned vendor through the job lifecycle (status, schedule, check-in/out, emails, estimates)

    Pin candidates for later, broadcast the job to nearby vendors, or duplicate the job to another location

    Think of it as: read the job → pick a vendor → assign & send work order → track the vendor until the job moves forward.



    Open job Review Job Details Find vendor Assign / Send W/O Manage vendor card Status actions & schedule


  1. ‌How you get here

    Entry URL pattern

    Admin Portal V2 http://localhost:4200/job/{jobKey}/assign-vendor

    From legacy Admin Often opened with ?token= JWT in the URL for authentication


    The page reads jobKey from the route. If it is missing, a toast error explains that you must navigate from a valid job.

    ‌Authentication: The route uses authGuard. The JWT may come from ?token= on first load or from browser storage afterward. If APIs fail with “unreachable,” the page surfaces a message pointing at API configuration and login.

Work Order modal highlights:

Spoken to vendor? (Yes/No)

Schedule date? (picker or ETA limit in days)

Optional DNE change

Attach uploads + select existing job/location files

Vendor Selection Survey (required factors + admin remarks)

Send with or without attachments

After send, vendor appears under Selected Vendors and may receive QC manager notification modals.


    1. Add Vendor To This Job (form, without immediate W/O)

      Uses vendor + contact dropdowns. May trigger:

      Duplicate-vendor warning

      Already-assigned alert

      Assign-vendor modal when reactivating an inactive vendor (reset status/schedule or keep)


    2. Onboard Outside Vendor

      Modal form: company, contacts, address, trades, insurance flags, accounting contacts, etc. Duplicate detection can warn before Create Anyway.

    3. Unassign vendor

      Multi-step safety flow:

      1. Vendor bill exists? → warn about bill deletion

      2. Pending estimate approvals? → set NOT APPROVED or cancel

      3. Removing default with 2+ vendors? → pick new default

      4. Confirm removal (+ optional “Insufficient Performance” reason)

      5. Send cancellation email? (optional notes)


    4. Broadcast to Vendors

      Modal: adjust radius, multi-select vendors, send broadcast email to unassigned vendors in range.


    5. Duplicate this Job

      Pick another customer location → creates new job → link to open new job’s Assign Vendor page.


    6. Check-in / Check-out (admin)

      From vendor card status buttons:

      Check-in: date/time, number of techs

      Check-out: work performed, checkout time, status (complete / incomplete / etc.), work details


    7. Notes & messaging

      Customer / location / vendor email click

      Notes & Activity modal (vendor tab pre-selected when applicable)


      Grid “Send Msg” / contact column Notes & Activity modal

  3. Glossary

    Term Meaning


    Job Key Unique GUID for the service job; in the URL


    Term Meaning


    Default vendor

    Primary assigned vendor for workflow defaults (W/O, on-site approval, schedule panel)

    Primary vendor

    Customer’s contracted/preferred vendor for the trade+location (may auto-assign on customer jobs)

    NTE

    Not To Exceed — spending cap (customer vs vendor views)

    DNE

    Do Not Exceed — vendor-specific cap on the job

    W/O

    Work order — email package sent to vendor to accept the job

    TriggerBit / Status

    Internal workflow stage driving which action buttons appear

    Scorecard Agent

    AI scoring of internal vendors for this job (distance, history, workload, etc.)

    Sourcing Agent

    AI discovery of external businesses near the job

    Maybe / No pin

    Shortlist markers while reviewing internal vendor candidates

    Upline approval

    Customer approval gate before dispatch proceeds

    Consolidator vendor

    Special vendor type requiring extra confirmation

    ‌Location history

    Vendors who previously performed work at this store/site
